Reinforcement learning

A Guide to the Two Major Types of Reinforcement Learning

Reinforcement learning (RL) is a machine learning paradigm where an agent learns to make decisions by interacting with an environment. The agent receives rewards or penalties based on its actions and learns to maximize cumulative reward over time. There are two major approaches to solving RL problems: model-free and model-based reinforcement learning.

Model-Free Reinforcement Learning

Model-free RL methods learn directly from experience without building an explicit model of how the environment works. The agent learns a policy (how to act) or a value function (how good states/actions are) through trial and error.

Key characteristics:

  • The agent doesn't try to understand or predict the environment's dynamics
  • Learning happens through direct interaction and observation of rewards
  • Generally simpler to implement but can require many interactions with the environment

Two main approaches:

Value-based methods learn to estimate the value of being in different states or taking different actions. The most famous example is Q-learning, where the agent learns a Q-function that estimates the expected future reward for each state-action pair. The agent then acts by choosing actions with the highest Q-values.

Policy-based methods directly learn a policy that maps states to actions, often using gradient ascent to improve the policy. Examples include REINFORCE and actor-critic methods. These approaches can handle continuous action spaces more naturally than value-based methods.

Example: Teaching a robot to walk. The robot tries different movements, receives rewards for making forward progress, and gradually learns which actions lead to better outcomes without understanding the physics of walking.

Model-Based Reinforcement Learning

Model-based RL methods first learn or use a model of the environment that predicts how the environment will respond to the agent's actions. This model can then be used for planning and decision-making.

Key characteristics:

  • The agent builds an internal representation of environment dynamics (what happens when I take action A in state S?)
  • Can plan ahead by simulating future scenarios using the learned model
  • Typically more sample-efficient but computationally more complex

How it works:

The agent learns a transition model P(s'|s,a) that predicts the next state given the current state and action, and sometimes a reward model R(s,a). With this model, the agent can "imagine" the consequences of different action sequences and choose the best one through planning algorithms like tree search.

Example: A chess program that has learned the rules of chess (the model) can look ahead several moves to evaluate different strategies without actually playing those moves on the board.

Comparing the Two Approaches

Model-free methods excel when the environment is complex and difficult to model accurately, or when you have access to unlimited interactions with the real environment. They're also simpler to implement and debug.

Model-based methods shine when data is expensive or limited (like controlling real robots where crashes are costly), or when the environment follows predictable rules. Being able to plan using an internal model makes them more sample-efficient, though the quality of learning depends heavily on the accuracy of the learned model.

In practice, modern RL often combines both approaches, using model-based components to improve the sample efficiency of model-free algorithms. The choice between these approaches depends on your specific problem, computational resources, and how much experience you can afford to gather from the real environment.

On-Policy vs Off-Policy: Another Important Distinction

On-policy and off-policy represent a different type of division within reinforcement learning. This distinction is actually a subdivision within model-free RL, not related to the model-based vs model-free classification.

The Classification Hierarchy

Main division: Model-free vs Model-based (as explained above)

Within Model-free RL: On-policy vs Off-policy

On-Policy Methods

On-policy methods learn about and improve the same policy they're currently using to act. The agent learns from experience generated by its current policy.

Examples:

  • SARSA (State-Action-Reward-State-Action)
  • Policy gradient methods like REINFORCE
  • A3C (Asynchronous Advantage Actor-Critic)

Key characteristic: "I learn from what I'm currently doing"

Off-Policy Methods

Off-policy methods can learn about one policy (the target policy) while following a different policy (the behavior policy). The agent can learn from experience generated by other policies, including old experiences or even human demonstrations.

Examples:

  • Q-learning
  • DQN (Deep Q-Network)
  • DDPG (Deep Deterministic Policy Gradient)

Key characteristic: "I can learn from data generated by other policies or my past behavior"

Why This Matters

Off-policy methods are generally more sample-efficient because they can reuse old experience (through techniques like experience replay), while on-policy methods typically need fresh data from the current policy. However, on-policy methods are often more stable and easier to implement.

Summary: Model-free vs model-based describes how the agent learns, while on-policy vs off-policy describes what data the agent learns from.
